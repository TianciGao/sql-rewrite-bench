# R-Bot PG15 Execution Expansion 02

This package prepares a human-run PostgreSQL-only execution and validity check
for the `15` generated rows retained by
`r_bot_pg40_generation_expansion_02`.

Boundary:

- PG only
- execution and validity only
- no timing
- no speedup
- no leaderboard claim

This package does not upgrade R-Bot into full PG40 validity evidence by
itself. The `25` failed generation rows remain explicit in the PG40 generation
denominator outside this execution subset. Existing PG7 retained evidence also
remains untouched.
