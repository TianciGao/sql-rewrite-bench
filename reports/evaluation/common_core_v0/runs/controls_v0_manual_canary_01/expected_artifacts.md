# Expected Artifacts

This manual canary executes case-level validation scripts, not per-control commands. The validation scripts are expected to execute `source.sql`, `rewrite_pos_01.sql`, and `rewrite_neg_01.sql` together and then write checker artifacts under the case-local `runs/` tree.

Run-local artifacts expected in this directory:
- `logs/env_check.stdout.log`
- `logs/env_check.stderr.log`
- `logs/perf_0006_pg_validation.stdout.log`
- `logs/perf_0006_pg_validation.stderr.log`
- `logs/perf_0006_mysql_validation.stdout.log`
- `logs/perf_0006_mysql_validation.stderr.log`
- `run_results.json`

Case-local artifacts that may be regenerated by the validation scripts:
- `cases/PERF/PERF_0006/runs/pg/result_check.json`
- `cases/PERF/PERF_0006/runs/pg/source.tsv`
- `cases/PERF/PERF_0006/runs/pg/rewrite_pos_01.tsv`
- `cases/PERF/PERF_0006/runs/pg/rewrite_neg_01.tsv`
- `cases/PERF/PERF_0006/runs/mysql/result_check.json`
- `cases/PERF/PERF_0006/runs/mysql/source.tsv`
- `cases/PERF/PERF_0006/runs/mysql/rewrite_pos_01.tsv`
