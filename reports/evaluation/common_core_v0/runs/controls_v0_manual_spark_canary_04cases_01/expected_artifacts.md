# Expected Artifacts

This manual canary executes case-level Spark validation scripts, not per-control commands. The validation scripts are expected to execute `source.sql`, `rewrite_pos_01.sql`, and `rewrite_neg_01.sql` together and then write checker artifacts under each case-local `runs/spark/` tree.

Run-local artifacts expected in this directory:
- `logs/env_check.stdout.log`
- `logs/env_check.stderr.log`
- `logs/perf_0006_spark_validation.stdout.log`
- `logs/perf_0006_spark_validation.stderr.log`
- `logs/cons_0007_spark_validation.stdout.log`
- `logs/cons_0007_spark_validation.stderr.log`
- `logs/longtail_0011_spark_validation.stdout.log`
- `logs/longtail_0011_spark_validation.stderr.log`
- `logs/port_0012_spark_validation.stdout.log`
- `logs/port_0012_spark_validation.stderr.log`
- `records.tmp.jsonl`
- `run_results.json`

Case-local artifacts that may be regenerated by the validation scripts:
- `cases/CONS/CONS_0007/runs/spark/result_check.json`
- `cases/CONS/CONS_0007/runs/spark/source.tsv`
- `cases/CONS/CONS_0007/runs/spark/rewrite_pos_01.tsv`
- `cases/CONS/CONS_0007/runs/spark/rewrite_neg_01.tsv`
- `cases/LONGTAIL/LONGTAIL_0011/runs/spark/result_check.json`
- `cases/LONGTAIL/LONGTAIL_0011/runs/spark/source.tsv`
- `cases/LONGTAIL/LONGTAIL_0011/runs/spark/rewrite_pos_01.tsv`
- `cases/LONGTAIL/LONGTAIL_0011/runs/spark/rewrite_neg_01.tsv`
- `cases/PORT/PORT_0012/runs/spark/result_check.json`
- `cases/PORT/PORT_0012/runs/spark/rewrite_pos_01.tsv`
- `cases/PORT/PORT_0012/runs/spark/rewrite_neg_01.tsv`

Interpretation note:
- these validation scripts are the execution step
- later control-row derivation should read the resulting `result_check.json` artifacts rather than pretending that `native_source`, `human_positive`, and `hard_negative` are separate executable commands
- if a Spark validation script is absent, the run script records `missing_script` and continues
