# R-Bot PG15 Timing Expansion 02

This package prepares a human-run PostgreSQL-only timing pass for the `15`
rows that were generated in `r_bot_pg40_generation_expansion_02` and then
passed exact-match execution in `r_bot_pg15_execution_expansion_02`.

Boundary:

- PG only
- timing only
- no leaderboard claim
- no method comparison update

This package does not imply timing evidence for all PG40 rows, for the full
`common_core_v0_40_same_engine_120` denominator, or for any tri-engine
comparison. The `25` failed PG generation rows remain explicit outside this
timing subset. Existing PG7 retained timing evidence remains untouched.
