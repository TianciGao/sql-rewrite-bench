# Expected Artifacts

This manual run executes case-level validation scripts, not per-control commands. The validation scripts are expected to execute `source.sql`, `rewrite_pos_01.sql`, and `rewrite_neg_01.sql` together and then write checker artifacts under each case-local `runs/` tree.

Run-local artifacts expected in this directory:
- `logs/env_check.stdout.log`
- `logs/env_check.stderr.log`
- `logs/<case_id>_pg_validation.stdout.log`
- `logs/<case_id>_pg_validation.stderr.log`
- `logs/<case_id>_mysql_validation.stdout.log`
- `logs/<case_id>_mysql_validation.stderr.log`
- `records.tmp.jsonl`
- `run_results.json`

Case-local artifacts that may be regenerated by the validation scripts:
- `cases/<POOL>/<CASE>/runs/pg/result_check.json`
- `cases/<POOL>/<CASE>/runs/pg/source.tsv`
- `cases/<POOL>/<CASE>/runs/pg/rewrite_pos_01.tsv`
- `cases/<POOL>/<CASE>/runs/pg/rewrite_neg_01.tsv`
- `cases/<POOL>/<CASE>/runs/mysql/result_check.json`
- `cases/<POOL>/<CASE>/runs/mysql/source.tsv`
- `cases/<POOL>/<CASE>/runs/mysql/rewrite_pos_01.tsv`
- `cases/<POOL>/<CASE>/runs/mysql/rewrite_neg_01.tsv`

Interpretation note:
- these validation scripts are the execution step
- later control-row derivation should read the resulting `result_check.json` artifacts rather than pretending that `native_source`, `human_positive`, and `hard_negative` are separate executable commands
- if any validation script is absent, the run script records `missing_script` and continues
